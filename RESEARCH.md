# Flood-Risk Research

Academic flood-risk research and the authoritative 2014-2025 daily IMERG dataset are maintained in the sibling repository at `../distributionMapApp-research` and in the private GitHub repository [ElGuill3/distributionMapApp-research](https://github.com/ElGuill3/distributionMapApp-research).

That repository owns research methodology, provenance, acquisition tooling, archived experiments, and data integrity records. This application repository does not own or version the research dataset. Do not copy canonical research data into the application tree or treat application behavior as scientific validation.
